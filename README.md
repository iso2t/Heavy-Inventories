# Heavy Inventories

Heavy Inventories brings the feel of RPG inventory management to Minecraft. Inspired by games such as The Elder Scrolls, it gives the things you carry a sense of weight and makes preparing for an adventure part of the adventure itself.

The aim is a realistic system with weights that suit Minecraft: believable choices, added difficulty, and a natural fit with the game. This repository contains the shared codebase and its Fabric and NeoForge implementations.
