# 4.263.0.0-rc.1

Release candidate for Minecraft 26.3, available for Fabric and NeoForge.
Published as Beta on CurseForge and Modrinth, and as a prerelease on GitHub.

## Added

- Soaring I-IV for elytra reduces weight-induced lift and rocket penalties by 20% per level, capped at 80%.
  Obtain enchanted books through the enchanting table and apply them with an anvil.
- Configurable weight penalties for elytra flight. Heavier loads reduce glide lift and rocket thrust, with default
  maximum reductions of 15% and 25% at 1,000 pounds.
- Flight penalties use actual carried weight, including container contents. Carrying-capacity bonuses do not reduce
  them. Players can still deploy elytra while overloaded.
- Server operators can configure or disable the penalties under Elytra flight in the server settings screen.

## Changed

- Updated to Minecraft 26.3 and its matching loader and Cloth Config dependencies.
- Added weight defaults for poplar logs, leaves and saplings, red shrubs, shelf mushrooms, and explorer maps.
  Crafted additions, including poplar building blocks, cushions, straw beds, and wool/concrete variants, derive
  their weights from recipes.

## Fixed

- Bounded incoming item-weight tables to prevent excessive client memory use from malformed server updates.
  Invalid tables preserve the last valid weights.

## Installation and upgrading

- Requires **Minecraft 26.3 and Java 25**. Install matching Heavy Inventories versions on clients and servers.
- Use **Fabric Loader 0.19.5 with Fabric API 0.160.6+26.3**, or **NeoForge 26.3.0.3-beta** or newer for Minecraft 26.3.
- Requires **Cloth Config 26.3.159** for the matching loader. NeoForge dedicated servers can omit it.
- Existing server configurations use the enabled flight defaults. Set `effects.elytra.enabled` to `false` to retain
  vanilla flight behavior.
- This begins the `4.263` release line. The jars do not support Minecraft 26.2.
