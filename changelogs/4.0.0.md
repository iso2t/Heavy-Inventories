# 4.0.0

Full release of Heavy Inventories 4 for Minecraft 26.1.2, available for Fabric and NeoForge.

## Highlights

- Inventory weight includes equipped armor, offhand items, and nested vanilla container contents. Default carrying capacity is 1,000 pounds, with weights scaled for Minecraft gameplay.
- Bundled material weights, recipe-derived weights, and server-side datapack overrides give modpack authors control over item balance.
- Choose progressive walking slowdown or slowdown beginning at 90% capacity. Strength, Bracing, and Reinforced increase carrying capacity; Surefooted helps movement while encumbered.
- Configurable hunger exhaustion, gradual fall penalties, swimming slowdown, sinking, and weight-based knockback resistance. Optional upward swimming denial is off by default. Each effect has independent server controls.
- A weight ring behind the XP level, optional numeric displays, adjustable ring placement, and compact weight tooltips provide native-looking feedback.
- Operators can edit server settings in-game, reload configuration, export weight reports, and convert legacy weight files into reviewable datapacks.

## Changes since RC2

- Updated from Minecraft 26.1 to 26.1.2 with the corresponding Fabric and NeoForge dependencies.
- Updated the multiloader build to the 26.1.2 template while preserving existing gameplay, datapack behavior, and publishing support.
- Promoted the release from beta to stable. The gameplay defaults are unchanged from RC2.

## Fixes included in 4.0.0

- Encumbrance-blocked ground jumps do not consume exhaustion or increment the jump statistic.
- Weight does not turn harmless short or cushioned falls into damaging falls; normal fall protections remain effective.
- Weight state and temporary resistance rebuild correctly across inventory changes, respawn, dimension travel, and reconnect.
- Unchanged player weight/settings snapshots are no longer resent every second.

## Installation and upgrading

- Requires **Minecraft 26.1.2 and Java 25**. Install matching Heavy Inventories versions on both client and server, using the jar for your loader.
- Verified with **Fabric Loader 0.18.6 and Fabric API 0.145.4+26.1.2**, or **NeoForge 26.1.2.7-beta**.
- **Cloth Config 26.1.154** is required on Fabric and on NeoForge clients. NeoForge dedicated servers can omit it.
- Update Minecraft and loader dependencies when upgrading from the 26.1 release candidates. These jars do not target Minecraft 26.1.
- Existing configuration files retain their settings and use defaults for missing effect fields. Exhaustion and knockback resistance default to enabled; upward swimming denial defaults to disabled. Disabling these effects does not disable the separate walking slowdown and ground-jump restriction.
