# 4.262.0.0

Heavy Inventories 4 for Minecraft 26.2, available for Fabric and NeoForge.

## Changed

- Updated to Minecraft 26.2 and its corresponding Fabric, NeoForge, and Cloth Config dependencies.
- Adopted four-part versioning: `4.<Minecraft line>.<feature>.<patch>`. `4.262.0.0` begins the Minecraft 26.2 release
  line.
- Added material defaults for cinnabar, sulfur, potent sulfur, sulfur spikes, sulfur cube buckets, and the new music
  disc. Crafted building variants derive their weights from recipes.

## Installation and upgrading

- Requires **Minecraft 26.2 and Java 25**. Use the jar for your loader and matching Heavy Inventories versions on
  clients and servers.
- Requires **Fabric Loader 0.19.3 and Fabric API 0.152.1+26.2**, or **NeoForge 26.2.0.1-beta** or newer for Minecraft
  26.2.
- **Cloth Config 26.2.155** is required on Fabric and NeoForge clients. NeoForge dedicated servers can omit it.
- Update Minecraft and loader dependencies when moving from the 26.1.2 release line. These jars do not target Minecraft
  26.1.2.
- Includes the 4.0.1 fix for weights falling back to 0.1 during new-world creation.
