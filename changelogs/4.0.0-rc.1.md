# 4.0.0-rc.1

Release candidate for Minecraft 26.1, with separate Fabric and NeoForge builds. Install the matching loader jar on both the client and server. Java 25 is required.

## Added

- Inventory weight and encumbrance, including equipped armor, offhand items, and nested vanilla container contents.
- Bundled material weights, recipe-derived item weights, and server-side datapack overrides. Successful reloads update connected players automatically.
- A choice of progressive walking slowdown or slowdown beginning at 90% carrying capacity.
- Carrying bonuses from Strength, Bracing, and Reinforced, plus Surefooted movement support.
- A weight ring behind the XP level, an optional numeric display, adjustable ring placement, and compact weight tooltips.
- Operator configuration, weight reports, and conversion of legacy weight JSON files into reviewable datapacks.

## Fixed

- Configuration filesystem failures are reported consistently on Linux and Windows. Failed reads or replacements preserve existing configuration data.

## Compatibility and upgrade notes

- Default carrying capacity is 1,000 pounds. Material differences aim to feel believable while the weights are scaled for Minecraft gameplay.
- Tested baseline: Fabric Loader 0.18.5 with Fabric API 0.144.0+26.1, or NeoForge 26.1.0.1-beta. Cloth Config 26.1.154 is required on Fabric and on NeoForge clients; NeoForge dedicated servers do not require it.
- Client and server must use matching Heavy Inventories builds. Older network peers are unsupported.
- Legacy weight JSON files no longer affect gameplay; convert them to datapacks and enable the resulting pack in the intended world.
- Custom backpack APIs and Ender Chest storage are outside the weight calculation scope. Third-party movement/HUD mods, shaders, and custom resource packs remain unverified.
- Stamina, carrying-capacity training, and dropped-item density are not implemented.

This candidate is intended for gameplay and balance feedback.
