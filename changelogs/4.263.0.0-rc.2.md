# 4.263.0.0-rc.2

Second release candidate for Minecraft 26.3, available for Fabric and NeoForge.

## Changed

- Replaced Cloth Config with EasyConfig for the client and server settings screens.
- Client preferences are accessible from Fabric's Mod Menu and NeoForge's mod-list config button.
- Settings screens edit a temporary draft. Save applies valid changes; Done closes without saving, Reload reads the
  latest client file or synchronized server settings, and Reset restores defaults in the draft. Invalid input blocks saving.
- Client and server settings now use EasyConfig-generated TOML files.
- Server edits retain operator permission checks and validation; item-weight datapacks continue to use JSON.

## Installation and upgrading

- Requires **Minecraft 26.3 and Java 25**, with matching Heavy Inventories builds on clients and servers.
- Install **EasyConfig 1.263.0.9 or newer** for your loader. Fabric also requires Fabric API.
  EasyConfig is required on both clients and dedicated servers, including NeoForge.
- Heavy Inventories no longer requires Cloth Config. Keep it installed if another mod needs it.
