# 4.0.1

Bug-fix release for Minecraft 26.1.2, available for Fabric and NeoForge.

## Fixed

- Fixed all items falling back to 0.1 weight when creating a singleplayer world. Bundled weights and custom datapack overrides now survive world creation and remain available when reloading server settings.

## Upgrading

- Replace the 4.0.0 jar with 4.0.1 for your loader. Use matching Heavy Inventories versions on clients and servers.
- Minecraft, loader, and dependency requirements are unchanged from 4.0.0. Existing worlds, configuration files, and weight datapacks need no migration.
